# 东北电力大学自动化工程学院 · 成绩查询与安全管理平台

本系统是专为东北电力大学自动化工程学院打造的现代化、高安全性教务成绩查询与权限管控系统。系统彻底重构了原前端明文存储学生成绩与密码的安全隐患，引入了基于 Netlify Functions 与 Netlify Managed Database (Postgres) 的全套后端安全防护体系与管理员权限控制台。

## ✨ 核心特性

### 1. 🛡️ 深度安全防护与零泄露架构
- **数据完全后端化**：学生数据库（581 名学生、各科成绩、8位出生年月密码）移至后端托管数据库，前端打包产物中不包含任何学生隐私数据，彻底杜绝 F12/源码泄露。
- **三重身份核验**：强制校验班级、姓名与8位出生年月密码，三者完全匹配后仅返回该学生本人的脱敏成绩。
- **防暴力破解与 IP 频控**：连续失败尝试超阈值（默认5次）自动触发滑动窗口锁定（默认15分钟），并记录告警。
- **时序攻击防护 (Timing-safe Comparison)**：管理员鉴权及密码比对采用常数时间算法，杜绝侧信道时序攻击。
- **防伪数字水印与校验码**：学生成绩单上动态生成包含学生姓名、脱敏学号、查询时间戳及数字签名的防篡改防截图水印。
- **全量安全审计日志**：对每次查询、拦截、失败、封禁、管理员操作进行实时落盘审计。
